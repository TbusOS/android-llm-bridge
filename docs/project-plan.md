## 二、主线：远程调试台架

2026-10-14 定的主线：先把「在 Linux 上经 Web + 串口 + USB 调 Windows 那头的板子」做好 ——
控制台敲命令、读写文件、看日志定位、验证、烧录、看 Windows 侧日志。

```
 Linux(hub)                                Windows(台架)
 alb 命令行 / MCP / 网页 ──> hub ◄── 出站拨回 ── 台架 agent ── USB / 串口 ── 板子
                             │                     │
                             │  adb、串口字节原样转发(只改 Linux 就能加功能)
                             │  fastboot、9008、USB 枚举、Windows 日志
                             └─ 走 agent 的操作表(加一个操作登记一行)
```

命令按「要不要动 Windows」分三类：adb 和串口只改 Linux;必须在 Windows 上跑的进台架 agent 的操作表
(ADR-059),agent 可以由 hub 远程换版(ADR-060)。当时分的三批都做完了：

| 批次 | 内容 | 出处 |
|---|---|---|
| 第一批(要换一次 Windows agent) | 操作表;fastboot erase / set-active / boot 单独命令;USB 列表认出板子在哪种模式;Windows 侧日志(agent 自己的、USB 驱动的)只读取尾部 | ADR-059 |
| 第二批(只改 Linux) | 上电停在 bootloader;root + remount;pstore 内核日志;设备端口通道(`alb port`);logcat / dmesg / 串口合并时间轴;网页整包烧录 | ADR-056、ADR-058、`alb timeline`、`alb port` |
| 第三批(下载模式) | 高通 9008(EDL)三个操作：送 programmer、按清单写、重启出 9008 | ADR-066 |

围绕它补的：远程拉起台架 agent(ADR-061)、台架板子表与运行中切换串口(ADR-063)、
adb 端点由代码解析(ADR-057)、推大镜像偶发断开的修复(ADR-065)。

## 四、接下来

### 1. 能马上做的(网页助手质量)

| 问题 | 依据 |
|---|---|
| 英文界面打招呼，第一步总是先调工具 | 2026-11-09 测试：你好 / hello / hi 各 10 次，都是 10/10 |
| 长工具结果截短后，小模型答不全也不说 | 2026-11-05:6 个错误码只答了 3 个;工具卡上已标出截短，模型这边没改 |
| 带工具的一轮还是慢 | 2026-11-05:模型每一步 1.1–2.5 s;工具结果长的两道题，截短后一轮仍要 17–92 s(纯 CPU 推理)。「只发和问题相关的工具」没做 |

### 2. 等自然碰到再验证的

- 9008 写闪存那一步失败时的退出码和输出(送 programmer 失败那条路验过)
- 推大镜像偶发断开的修复，没在台架上撞过一次长推送
- 两块板子同时在线、又没指定板子时的行为(台架只有一块)
- 模型服务那台机器真关机时的报错(模拟过端口不通和包没人回)

### 3. 要等硬件或需求出现

| 功能 | 什么时候做 |
|---|---|
| 别家芯片的下载模式 | 这类板子上台架、Windows 上有命令行版工具时 |
| 9008 配置按板子分开 | 第二个 9008 产品上台架时 |
| 一台 Windows 接两块板 / 多台 Windows | 真有第二个台架 agent 时(多 agent 寻址，技术债 DEBT-083/084) |
| MCP 补烧录、台架、9008、时间轴、端口类工具 | 有人要让模型经 MCP 直接做这些时;现在走命令行 |

## 五、不做 / 延后

| 项 | 理由 |
|---|---|
| 断电重启(power cycle) | 台架没有可控电源或继电器 |
| `fastboot flashing unlock/lock` | unlock 会清数据，lock 配错镜像会让板子起不来 |
| 设备端模型 | 现在不开发;操作表、设备端口通道、模型后端注册表三处留了接入口 |

## 六、质量门槛

| 门槛 | 要求 |
|---|---|
| 敏感词 | `scripts/check_sensitive_words.sh` 退出码 0,提交说明里也不能有 |
| ruff / mypy | 改动不新增条目(仓里有存量，按条目比，不看总数) |
| 测试 | 新行为配测试，并拿改动前的代码反跑一遍，确认测试会挂 |
| 网页 | `npm run typecheck`;改了界面在真实浏览器里点一遍(`web/scripts/` 下的功能检查) |
| 提交说明 | 中文正文，不带 LLM 署名(见 `contributing.md`) |

真实进度以 `git log` 和 `docs/design-decisions.md` 为准，这份文档跟着大的变化更新。
