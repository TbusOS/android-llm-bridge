3 · 执行

POST /api/flash/plan/run

会写到 board-a。第一次写入前会再读一次 product,必须是 board_x。执行 28 行,包括 userdata,在这里撤不回。

执行时可以关掉页面,作业会继续跑;回来在这里和「最近作业」里都能看到结果。
