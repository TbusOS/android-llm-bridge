Debug a board from the browser在浏览器里调试板子

The hub serves a web UI at /app/: board state, adb shell and serial console, logs, one timeline for every source, fastboot flashing and the bench machine, with an assistant you can pull out on any page. It follows Google's Material 3, comes in light and dark, and treats Chinese and English as equals. hub 在 /app/ 提供网页界面：看板子状态、开 adb shell 和串口、查日志、把各路日志对到同一条时间轴、用 fastboot 烧录、管理台架电脑，任何页面都能拉出助手。界面按 Google 的 Material 3 规范做，有浅色和深色，中文和英文同等对待。

Open the overview design打开总览设计稿 7 styles compared7 套风格对比 Web API referenceWeb API 参考

The screenshots and design pages below use sample data and are not connected to any board. To use the real UI, start alb-api (port 8765 by default) and open http://<host>:8765/app/. 下面的截图和设计稿用的都是示例数据，不连任何板子。要用真正的界面，启动 alb-api（默认端口 8765），再打开 http://<host>:8765/app/。

Overview总览

Device设备

Start here: which devices are online, which boot stage the current board is in, which of the four channels reach it, which part of the last boot was slow, and what crashed lately. Further down is the whole alb service at a glance: which model backends respond and which agent sessions are running. 打开网页先看这里：哪些设备在线、当前板子停在开机的哪一步、四条通道哪几条能连上、上次开机慢在哪一段、最近有哪些崩溃。页面下方是整个 alb 服务的概况：哪些模型后端能用、有没有正在跑的 AI 会话。

Console控制台

Device设备

adb shell and the serial console in the browser, one tab each; saved commands run with one click and every command lands in the audit log. On the serial tab a Typing switch keeps stray keys away from the board, so they cannot stop the boot countdown. 在浏览器里开 adb shell 和串口控制台，一个页签一个；常用命令点一下就跑，每条命令都记进操作记录。串口页签有「键盘输入」开关，关着时按键不发给板子，免得误按停住开机倒计时。

Open the interactive design打开交互设计稿

Logs日志

Device设备

Live logcat, kernel messages and serial output, filtered by level, tag or keyword, plus search across everything already recorded. Serial output can be captured to a file and the captures are listed for opening or deleting; from any line, jump to the timeline to see what happened around it. 实时看 logcat、内核日志和串口输出，按级别、tag、关键字过滤，也能在所有已录下的日志里搜。串口输出可以抓一段存成文件，抓过的文件列在页面上，能打开也能删；看中某一行，可以跳到时间轴看它前后发生了什么。

Timeline时间轴

Device设备

Serial, dmesg, logcat and flash jobs on one clock. When a boot is slow or crashes, this is where you see what went wrong first; one button jumps to the first problem. 串口、dmesg、logcat 和烧录作业放在同一个时钟上。板子开机变慢或崩溃时，在这里看谁先出事，一个按钮跳到第一个问题。

Flash烧录

Flash烧录

Flash a whole package or one partition with fastboot, or type fastboot commands. A whole package becomes a plan first: untick the rows you don't want, then run it. The board is identified before anything is written, and the serial console is recorded throughout. 用 fastboot 烧整包、烧单个分区，或者直接敲 fastboot 命令。整包先出计划，在表格里勾掉不烧的行再执行；写之前先核对板子是谁，全程同时录串口。

Bench台架

Bench台架

The Windows machine the boards are plugged into: which board sits on which serial port, which USB devices it sees and whether their drivers are installed. Update or start its agent remotely, and read the bench logs in a large view. 板子插着的那台 Windows 电脑：哪块板接在哪个串口、USB 上看到哪些设备、驱动装好没有。那边的 agent 可以远程更新和启动，台架日志可以放大到整屏看。

Chat对话

Assistant助手

Ask about the board in plain words and cite a log, a problem or a time range with @. With agent mode on, the model reads logs and runs alb tools itself; each tool call expands to show its arguments and output, and long output opens in a large view. The model can run on the host, behind a cloud API, or on the board. 用大白话问板子的事，用 @ 引用一段日志、一个问题或一段时间。开了 Agent 模式，模型会自己读日志、调用 alb 工具，每次调用都能展开看参数和输出，长输出可以放大查看；模型可以跑在本机、云端 API 或板子上。

Not built yet: the backend does not yet ask before a tool changes the board (the draft shows that step), and the on-board option can only look for an inference service so far. 还没做的：后端还不会在工具改动板子前先问你（设计稿里画了这一步）；板上模型目前只能探测板子上有没有推理服务。

Open the interactive design打开交互设计稿
Shared frame共用外框

On every page每一页都有的

The pages share one frame, so the board and its channels stay in view wherever you are. 所有页面共用一个外框，不管在哪一页，当前板子和它的通道状态都在眼前。

Top bar顶栏

Shows the active board and the state of its four channels: adb, serial, fastboot and the bench. Switch boards from the same place.一直显示当前板子，以及 adb、串口、fastboot、台架四条通道的状态。切换板子也在这里。

Grouped navigation分组导航

Five groups: Device, Flash, Bench, Assistant, System. Ctrl/⌘ K searches the pages; old /inspect/… addresses redirect to the new pages.分设备、烧录、台架、助手、系统五组。按 Ctrl/⌘ K 搜索页面；旧的 /inspect/… 地址会自动跳到新页面。

Assistant sheet助手侧栏

Opens from the top bar on any page and shares one conversation with the Chat page. On the overview, logs, timeline and problems pages, a line or a crash can be handed to it with its context.任何页面都能从顶栏拉出来，和对话页共用同一段对话。总览、日志、时间轴、问题页上的一行日志或一次崩溃，可以带着上下文直接交给它。

Chinese and English中文和英文

Both are first-class, not one translated from the other. Fonts ship with the page (Roboto Flex, Roboto Mono and a common-character subset of Noto Sans SC); nothing is fetched from the network.两种语言同等对待，不是一种翻译另一种。字体随页面打包（Roboto Flex、Roboto Mono 和 Noto Sans SC 常用字子集），不从网上加载。

Light and dark浅色和深色

Follows the system by default, or pin either one. Every colour is an M3 colour role (--md-sys-color-*), so a theme swaps one set of values.默认跟随系统，也可以固定浅色或深色。颜色都用 M3 的颜色角色（--md-sys-color-*），换主题只换这一组值。

Works at phone width手机上也能用

A navigation drawer on wide screens, a rail on medium ones, a pop-out menu on phones. Cards stack in one column and wide tables scroll inside their card.宽屏是导航抽屉，中等宽度变成窄的导航栏，手机上收进菜单按钮。卡片排成一列，宽表格在卡片里横向滚动。
